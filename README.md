## 🧠 AI Engineering Focus

I’m interested in building AI features that are grounded in relevant information and can work safely within real applications—not just standalone chat demos.

```text
Knowledge sources
      ↓
Document ingestion & chunking
      ↓
Embedding model ──→ Vector database (Pinecone)
                         ↓
                 Retrieval & ranking
                         ↓
             Context-grounded LLM response
                         ↓
             Application tools / MCP
```

**Areas I’m exploring and applying**
- **Embeddings & vector search:** representing content semantically and retrieving relevant context.
- **RAG pipelines:** grounding LLM responses in retrieved knowledge.
- **Advanced retrieval:** improving relevance through metadata filters, hybrid retrieval, and reranking.
- **Spring AI:** integrating models and retrieval workflows into Java applications.
- **MCP & tool integration:** connecting AI experiences with external tools and contextual resources.
- **Responsible application design:** access control, useful error handling, and clear boundaries around model output.
